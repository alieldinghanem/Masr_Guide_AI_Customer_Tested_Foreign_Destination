## خطوة القبول قبل HR

```powershell
cd frontend
npm ci
npm test
npm run lint
npm run build
```

بعدها شغّل `RUN_STARTUP_WINDOWS.bat` من جذر المشروع وافتح `http://localhost:5173`، وراجع Home / Destinations / Experiences / Journal / Project / AI / Planner على الكمبيوتر والموبايل. اختبر البحث عن Luxor والأقصر، وتبديل اللغة، وتسجيل حساب تجريبي، وراجع Console لأي JavaScript errors.
