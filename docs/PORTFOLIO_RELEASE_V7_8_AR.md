# Masr Guide AI — Verified Portfolio Candidate v7.8

**المنتج المستهدف:** منصة سياحية تروّج لمصر وتضم صفحات الوجهات والمعالم والتجارب والمقالات، وحسابات المسافرين، ومخطط الرحلات، والمرشد الذكي Gemini/RAG، ولوحة المحتوى والشركاء والإحالات. هذا **MVP قابل للاختبار** وليس مشغّل حجوزات تجاريًا مرخّصًا.

## التعديلات الجديدة على v7.7

- منع إرسال `thinkingBudget: 0` إلى نموذج Gemini ذي الاسم المتغيّر `gemini-flash-latest`، مع المحافظة على الإعداد المثبت للإصدارات التي تدعمه. اختبارات adapter منفصلة لكل نموذج.
- حفظ الرحلة الناتجة من المحادثة مباشرة داخل حساب المستخدم، بعد تسجيل الدخول، عبر API يفرض ملكية الرحلة؛ لم يعد حفظها مقصورًا على المتصفح.
- أداة نسخة احتياطية متسقة لقاعدة SQLite للحسابات والرحلات والمحادثات عبر SQLite Online Backup API، مع فحص integrity وforeign keys ومنع التخزين داخل مستودع الكود.
- اختبار نسخة احتياطية فعلي وتحقق من استقلالها عن تغيّر قاعدة البيانات بعد النسخ.
- تطوير سيناريو E2E لفحص تسجيل حساب حقيقي وحفظ رحلة وخروج آمن، إضافة إلى اكتشاف الأماكن والمخطط والشات على الكمبيوتر والموبايل. **الاختبار موجود لكنه لم يُنفَّذ بنجاح في بيئة التجهيز المقيدة.**
- اختبار Gemini opt-in يستدعي الخدمة فعليًا ويختبر أيضًا `/api/chat` مع RAG من داخل FastAPI، وليس مجرد Ping للنموذج.
- أداة فحص إصدار موحدة `scripts/verify_release_v78.py` تفشل إذا تعذر تشغيل Build أو اختبارات الواجهة، ولا تعتبر `NOT_EXECUTED` نجاحًا. تكتب النتائج في `release-verification-local.json` (مستبعد من Git).
- ملف `VERIFY_FULL_RELEASE_WINDOWS.bat` لتشغيل الفحوص على Windows، مع تثبيت npm ثم الاختبار. لا يستدعي Gemini الحي من تلقاء نفسه.

## خطوة واحدة للتحقق على Windows

1. فك ZIP، ثم افتح مجلد `Masr_Guide_AI` ببرنامج VS Code.
2. شغّل `VERIFY_FULL_RELEASE_WINDOWS.bat` من المجلد الأساسي. يحتاج Python وNode.js وإنترنت لتنزيل مكتبات npm أول مرة.
3. يجب أن تنجح اختبارات React/Vitest/Lint/Build وChromium. احفظ نسخة من `release-verification-local.json` وسجل التشغيل، واحذف منه أي معلومات شخصية قبل المشاركة.
4. **اختياري وبعد إصدار مفتاح جديد وإخفائه في `backend/.env`:** `python scripts/verify_release_v78.py --browser --live-gemini` لإجراء استدعاءات حقيقية لـGemini. هذه قد تستهلك من حدود أو رسوم مزوّد الخدمة.
5. GitHub Actions فيها وظائف `backend` و`frontend` و`browser`، لا تعتبر الإصدار مجتازًا إلا لو جميعها خضراء. النشر على Render/Docker يحتاج فحص رابط Live مستقل.

## نسخ SQLite الاحتياطية

بعد تشغيل السيرفر وإنشاء قاعدة البيانات، اختر **مجلدًا خاصًا خارج مشروع Git**:

```powershell
python scripts/storage_backup.py backup --output "$HOME\\Documents\\MasrPrivateBackups"
python scripts/storage_backup.py verify --file "C:\\path\\to\\traveler-YYYYMMDD.sqlite3"
```

قاعدة المستخدمين في النسخة الاحتياطية تحتوي بيانات شخصية ومعلومات مصادقة حساسة. لا تشاركها أو تضعها على GitHub أو تخزّنها دون تشفير وضوابط وصول. **لا تستبدلها تلقائيًا أثناء تشغيل السيرفر**؛ اختبر الاسترجاع في بيئة منعزلة قبل اعتبار خطة النسخ الاحتياطي كافية للإنتاج.
