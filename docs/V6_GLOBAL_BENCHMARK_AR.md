# Masr Guide AI v6 — مراجعة التصميم العالمي والتطوير

## المقارنة المرجعية

المقارنة مستوحاة من *أنماط تجربة المستخدم* العامة، مش نسخ صفحات أو علامات تجارية:

- **Visit Dubai** (`https://www.visitdubai.com/en/`): محتوى يلهم السفر قبل أي نموذج تخطيط؛ وجهات وتجارب ومعلومات عملية في تنقل واضح.
- **GetYourGuide** (`https://www.getyourguide.com/`): صور التجارب وفلاتر استكشافها، مسارات واضحة من الإلهام للاستفسار عن نشاط.
- **Tripadvisor Egypt** (`https://www.tripadvisor.com/Tourism-g294200-Egypt-Vacations.html`): اكتشاف الوجهات والمعلومات العملية وتقسيمات الاهتمامات.
- **Experience Egypt** (`https://www.experienceegypt.eg/en/home`): السرد السياحي الرسمي عن تنوع مصر بعيدًا عن الآثار وحدها.

## اللي اتنفذ على v5

1. Hero رئيسي بعرض الشاشة وروح تصوير سينمائية، عنوان كبير ودعوتين واضحين (Explore / Plan).
2. بحث حقيقي من الصفحة الرئيسية ينقل لصفحة الوجهات ويفلتر النتائج، بالعربي والإنجليزي.
3. أقسام وجهات مصوّرة، 6 وجهات في الصفحة الرئيسية، ومحتوى يحافظ على هوية كل مدينة.
4. أقسام للتجارب السياحية، وتصفح حسب History/Coast/Desert.
5. تحسين صفحات Destinations وExperiences بصور ذات صلة بالمحتوى بدل أيقونات كبيرة فقط.
6. تحسين المساحات والتباين والتدرج البصري والأزرار وحركة Hover والتجاوب مع الموبايل وRTL.
7. الحفاظ على الـPlanner والـAI والحسابات والحفظ وCMS والشركاء والـHR case study.
8. إصلاح عيب في `PageHeader` القديم كان يشير إلى متغير `children` غير معرّف، وكان ممكن يعطّل صفحات Journal وOffers وPartners وStaff وProject أثناء العرض.

## الحدود اللي لازم تبقى واضحة للـHR

- دي **منصة Portfolio/MVP** وليست شركة حجوزات تعمل تجاريًا.
- لا توجد أسعار/توافر حجوزات حقيقيين ولا شركاء متعاقد عليهم داخل النسخة الافتراضية.
- الصور محملة من CDN خارجي وفي حالة انقطاع الشبكة تظهر خلفيات بديلة؛ صور المشروع الأصلية تحتاج مراجعة حقوق قبل النشر التجاري.
- بناء React من بيئة إعداد الحزمة لم يكتمل بسبب عدم توفر كل Dependencies مع تعطل اتصالات npm؛ لازم `npm ci && npm run build && npm test` على جهازك أو GitHub Actions قبل اعتماد الـRelease للـHR.
- الحفظ الحالي يعتمد على SQLite والبيانات الحقيقية تحتاج استضافة دائمة ومراجعة أمنية قبل التسجيل العام.
